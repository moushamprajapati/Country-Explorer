COUNTRY EXPLORER - 7 pages
1. index.html     Login / Register (security question) / Forgot password
2. explore.html   Search countries + wishlist hearts + recent searches
3. wishlist.html  Wishlist: delete, undo, notes, visited, progress bar, filters
4. compare.html   Compare two countries side by side
5. planner.html   Trip budget planner with saved plans
6. profile.html   Edit name, change password, security question, delete account
7. admin.html     Admin dashboard (see users, delete users)

ADMIN LOGIN:  admin@countryexplorer.com   /   Admin@123
(Dark / light mode button is in the top menu.)

HOW TO RUN: keep the folder structure as it is, then open index.html
(or upload the whole folder to GitHub Pages).
Data is stored in the browser's localStorage (no backend).
